# Sprint 3.1 profile and avatar behavior

Profile edits reuse the founder/startup and mentor onboarding tables. The authenticated API derives the account ID from its access token. Founder updates are constrained to the founder's one startup (`startups.founder_id`); mentor update schemas do not accept role, user ID, account status, or approval metadata. Editing a mentor preserves the existing approval state and rejection reason. Profile edits are not approval decisions.

`GET` and `PUT /profiles/me` provide the current user's profile editor contract. Public profiles are available at `GET /profiles/mentors/:id` and `GET /profiles/startups/:id`, with browser pages at `/mentors/:id` and `/startups/:id`. Founder details are not public. Startup profiles are available only when complete and owned by an active, verified founder. Mentor profiles are available only when complete and the mentor is active and verified. Public response schemas explicitly allowlist fields and omit email, owner IDs, availability, help requests, auth identifiers, and moderation fields.

Avatars use local disk storage with no external provider or client-side secret. Uploads accept PNG, JPEG, and WebP only, up to 512 KiB; the API checks the file signature, generates a UUID name, stores the URL on the owning `users` row, and serves only UUID-named image files. The default storage directory is `apps/api/uploads/avatars` when the API is started from its workspace. Set `AVATAR_STORAGE_DIR` to an absolute persistent directory for deployments where the application filesystem is ephemeral. Run `npm run db:migrate` to add `users.avatar_url`. The local file store is suitable for development; production must provide durable storage and backups at the configured path.

Profile save mutations optimistically merge the submitted fields into the cached profile, restore the previous cache on failure, and replace it with the API response on success. Avatar upload displays an immediate local preview and a pending state; the server response supplies the durable URL.
